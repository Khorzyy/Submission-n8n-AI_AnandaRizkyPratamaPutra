> **Study Jam Capstone Hub**: Repositori ini merupakan wadah terpusat pengumpulan tugas akhir peserta Study Jam Mobile Development GDG On Widyatama University. Seluruh karya aplikasi peserta ditautkan secara modular menggunakan **Git Submodule**.

---

## Tentang Repositori Ini

Selamat datang di **Portal Pengumpulan Tugas Akhir Mobile Development GDG On Widyatama University**!

Repositori ini berfungsi sebagai **hub utama dan etalase portofolio bersama** bagi seluruh peserta yang telah berhasil membangun aplikasi Android dari kanvas kosong hingga rilis produksi menggunakan teknologi modern Jetpack Compose di bawah bimbingan instruktur [Dimas Dwi Ariyanto](https://github.com/pavelc4).

---

## Mengapa Menggunakan Git Submodule?

Dengan Git Submodule, repositori aplikasi tetap berada di akun GitHub pribadi masing-masing peserta sehingga bisa langsung dijadikan portofolio publik nyata yang bisa kamu pamerkan.
